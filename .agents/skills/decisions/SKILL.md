# Review uncertain decisions

Think deeply about the important decisions and choices made while working on
the current task. Reconsider the evidence and whether there are strong
alternatives that have not been considered.

Only report important decisions you are truly unsure about. Omit choices
where the available evidence already supports the best solution. Do not
invent uncertainty to fill the answer.

For each remaining decision, briefly state the choice, why you are unsure,
and the strongest overlooked alternative, if one exists.

Answer very concisely, in plain English. If no important decisions remain
uncertain, say so in one short sentence.
