# Historical design and implementation records

The files in this directory preserve design decisions and implementation
history. They are not current execution instructions or a source of release
status.

Use the current task/thread plan for active work. Use `knowledge/` for durable
project concepts, `.agents/skills/` for executable validation routing, and
`docs/validation/` for dated evidence. When an historical plan conflicts with
the repository, trust the repository and those current sources.
