# API reference

The reference comes from the public Core and MAUI assemblies built with this
site. The guides explain ownership, readiness and completion; the reference
lists the types, methods and property signatures.

- [Core types](xref:PageCurl.Core): controller, navigation, options and mesh geometry.
- [MAUI types](xref:PageCurl.Maui): image, live-content and spread controls.

Start with [quick start](getting-started.md) for a working control, or
[runtime rules](runtime.md) for threading and disposal.
