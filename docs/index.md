# PageCurl.Maui documentation

PageCurl.Maui provides .NET 10 MAUI controls for turning images, live views and
two-page spreads like stiff paper. Use the [public documentation](https://mariusmuntean.github.io/PageCurl-docs/)
for setup, usage and API reference. Start with the [README](../README.md), then
use these repository pages for architecture and validation details:

- [Contributing](../CONTRIBUTING.md): focused changes and validation selection.
- [Support](../SUPPORT.md): issue reporting and the current target baseline.
- [Security reporting](../SECURITY.md): private vulnerability intake.
- [Documentation publishing](documentation.md): site sources, validation and publication.
- [Architecture](architecture.md): project boundaries and frame flow.
- [Requirements](requirements.md): acceptance criteria and links to automated coverage.
- [Interaction and rendering](interaction-and-rendering.md): gestures, page
  geometry, shading, and performance choices.
- [Renderer comparison](renderer-comparison.md): Simple3D suitability and current choice.
- [Runtime contracts](runtime-contracts.md): image ownership, threading, and
  lifecycle rules.
- [Testing](testing.md): automated coverage and visual checks.
- [Platform notes](platform-notes.md): SDK, workloads, and host limitations.
- [Compatibility](compatibility.md): target and evidence matrix.
- [Release readiness](release-readiness.md): remaining production gates.
- [Requirements status](requirements-status.md): implemented behavior and open
  evidence work.
- [Expanded library design](expanded-library-design.md): approved content,
  spread, anchor, backside, haptic, and showcase contracts.
- [Validation records](validation/): dated evidence from completed runs.

The repository validation skill owns the command matrix. Validation records
contain evidence, while the other pages describe stable behavior and policy.
